# getjabuti.com

The website of [Jabuti](https://github.com/guilhermemauro/jabuti), a self-hosted agent harness
you can read end to end.

Built with [Astro](https://astro.build) and deployed to GitHub Pages on every push to `main`.

```sh
pnpm install
pnpm dev       # http://localhost:4321
pnpm build     # astro check + static build in dist/
```

Requires Node 26 (see `.nvmrc`) and pnpm 11.

Everything the site says about the product comes from Jabuti's
[README](https://github.com/guilhermemauro/jabuti#readme) and
[AGENTS.md](https://github.com/guilhermemauro/jabuti/blob/main/AGENTS.md). If they disagree, they
win: open an issue or a pull request here.
